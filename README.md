# StarRex

Shooter en Modo 7 para **Super Nintendo**, hecho en casa con IA para el canal NOAD (Not Only A Doctor).
El Escuadrón Jurásico contra el Monolito: historia, mapa del Sistema Saurio, 3 planetas, jefes y música propia.

## Descargar
ROM: **[starrex-v0.32.sfc](https://github.com/wakezip/starrex/releases/latest)** (en Releases).

## Cómo jugar
Ábrela en cualquier emulador de SNES (Snes9x, bsnes, Mesen o RetroArch con el núcleo Snes9x).
También funciona en un cartucho flash tipo FXPAK / EverDrive.

| Botón | Acción |
|---|---|
| Cruceta | Mueve la mira (la nave la sigue) |
| A | Disparar (mantén para el disparo cargado) |
| B | Turbo (mantén para acelerar) |
| Y | Frenar |
| X | Giro en U (X + abajo: rizo) |
| L o R (mantener) | Viraje cerrado |
| L + R | Pedir ayuda a la escuadrilla |
| SELECT | Bomba |
| START | Empezar / pausa |
